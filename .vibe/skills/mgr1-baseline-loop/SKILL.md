# MGR1 baseline verification loop

Order matters: generators first (they are deterministic and any diff is a
regression), then the compiled testbenches, then the suite.

## 1. Regenerate and prove idempotence

```bash
python3 tools/gen_csr.py          # CSR defs + docs/05 from ip/schema/csr_map.json
python3 tools/gen_docs.py         # docs/03 + docs/06 from the oracle/worksheet
python3 tools/gen_cascade_config.py   # 52-node table -> hls/common/cascade_config.h
python3 tools/gen_unroll_plan.py      # docs/09a-unroll-plan.md
python3 tools/gen_lut_header.py       # hls/common/activation_lut_contents.h
git diff --stat                       # any diff here is a regression
```

## 2. Compiled golden checks (C++17)

Use g++ or zig c++ (either works; sources are dependency-free plain C++):

```bash
cd hls/gru_sequence && g++ -std=c++17 -O2 -I../common \
    tb_gru.cpp gru_top.cpp ../common/activation_luts.cpp -o tb_gru
./tb_gru ../../vectors/golden/gru_window.vec        # expect: score -7226, bit-match
cd ../mnv2_features && g++ -std=c++17 -O2 -I../common \
    tb_conv.cpp ../common/activation_luts.cpp -o tb_conv
./tb_conv ../../vectors/golden/conv_sentinels.vec   # expect: PASS
```

## 3. Suite + elaboration

```bash
python3 -m pytest tests/ -q            # expect 59 passed
python3 tools/check_rtl.py             # expect 12 files parse + elaborate
```

## Hard rules (do not violate)

- `model/integer_oracle/oracle.py` is the single source of truth for
  numbers. INT8 symmetric weights, INT32 accumulators, gate inputs Q7.10
  round-half-to-even, LUT outputs Q1.15, committed hidden Q7.8.
- Generated artifacts are never hand-edited — regenerate, then commit the
  regenerated bytes if they changed. A diff after a no-op regen is a bug.
- Any oracle change requires regenerated vectors + docs + green pytest
  before commit.
- No new unit-test sprawl: the golden-vector testbenches + the pytest suite
  above are the gate set; do not add frameworks.
